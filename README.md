# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 冻结前比较与审批

正式冻结前，学院可以把当前候选快照与上一次冻结比较，并按变化策略路由审批：

- `POST /api/plans/{plan}/freeze-approvals/comparisons` 比较候选与基线，按学生数量、总学时、异常类型与敏感字段计算所需签署人（可在请求体 `policy` 中覆盖阈值）；
- `GET .../freeze-approvals/{id}/route` 查看所需、已满足与未满足的签署角色；
- `POST .../freeze-approvals/{id}/signatures` 签署，更高级别角色可覆盖较低级别要求；
- `POST .../freeze-approvals/{id}/invalidate` 手动失效；
- `POST .../freeze-approvals/{id}/publish` 签署完成后把候选固化为新的冻结快照。

比较结果固定到基线与候选两个快照指纹：任一快照发生变化（新事件、计划调整或出现更新的冻结）都会使未决审批自动失效；内容相同的重算幂等复用同一审批，被系统原因失效后可按修订版本重新发起。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询，以及审批的比较、路由、签署、失效、发布、并发重算、权限升级、阈值边界与重启恢复；运行过程中不需要单独的数据库或网络服务。
