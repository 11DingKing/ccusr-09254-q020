# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 冻结前比较与审批

正式冻结前，学院需把候选快照与上一次冻结比较：`POST /api/plans/{plan_version}/comparisons` 生成比较记录并固定到两个快照指纹，变化策略按受影响学生数量、总学时波动、异常类型（学生移除、未达标、待确认、负向修正）与敏感字段（达标状态、修正秒数）决定签署链（教务员 → 系主任 → 院长）。`GET .../route` 查看待签角色，`POST .../signatures` 按序签署，`POST .../invalidate` 显式作废，`POST .../publish` 在签署齐全且指纹未变时发布为正式冻结。签署或发布前会重算指纹，任一快照变化都会使审批失效；发布新冻结也会连带作废其余待审批比较。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询，以及冻结前比较审批的并发重算、权限升级、阈值边界与重启恢复；运行过程中不需要单独的数据库或网络服务。
